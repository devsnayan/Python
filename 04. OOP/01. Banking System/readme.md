# 🏦 Python OOP Banking System

A beginner-friendly Banking System built with **pure Python** to learn and practice **Object-Oriented Programming (OOP)** through a real-world example.

This project focuses on understanding Python OOP concepts, class relationships, object interaction, inheritance, abstraction, encapsulation, polymorphism, and basic application structure.

> **Purpose:** Learning and practice only. This is not a production-ready banking application.

---

# 📌 Project Overview

The Banking System simulates basic banking operations such as:

- Creating customers
- Creating bank accounts
- Savings Account
- Current Account
- Depositing money
- Withdrawing money
- Checking account balance
- Viewing transaction history
- Calculating account interest

The project is intentionally kept small and simple so that the main focus remains on **Python OOP concepts** instead of frameworks or complicated architecture.
